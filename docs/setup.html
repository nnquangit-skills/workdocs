workdocs

Setup

Clone one folder into your agent's skills directory; the pages it writes need nothing at all.

Prerequisites

  • An agent that supports the Agent Skills format (Claude Code and others): it loads SKILL.md when you say workdocs.
  • For the agent: a shell to list and search files, and a file editor. Nothing else is required (references/dependencies.md).
  • For the pages: nothing. No runtime, no framework, no network, no build step.
  • Optional helpers, used only when installed: a diagram skill (archify or diagram-design) for the architecture diagram, playwright-cli for browser QA, a Remotion skill for the optional video, token-save for reading discipline. The workmap skill is a separate product; see SKILL.md, "Work map".

Source: references/dependencies.md, SKILL.md compatibility line

Install

# for every project on this machine
git clone git@github.com:nnquangit-skills/workdocs.git ~/.claude/skills/workdocs

# or for one project only
git clone git@github.com:nnquangit-skills/workdocs.git /path/to/project/.claude/skills/workdocs

Any copy of the folder works: the skill is SKILL.md, assets/ and references/. A marketplace zip is built with bash scripts/package.sh (one top-level folder, dist/, docs/, demo/ and local files left out).

Source: README.md "Install", scripts/package.sh

Configuration

There is no configuration file and no environment variable. Behaviour is set by what you say and by three conventions in the pages:

WhereEffectDefault
Your request"workdocs" or "/workdocs" starts a run; "refresh the docs" regenerates only sections whose sources changed; "no promo" leaves the Work map card outall six pages, Work map card shown when workmap is absent
data-workdocs="keep" on a sectionThe section is never regeneratedmanaged sections are regenerated when their sources change
docs-theme in the browser's localStorageLight or dark for every page in docs/, shared with the workmap pagefollows the system theme

Source: SKILL.md "Writing pages" and "Work map", assets/workdocs.js, assets/page.html

Run

In a project, say workdocs. The agent surveys the tree, reads README, manifest, entry points, handlers, auth, config, environment example and test scripts, inventories any existing pages, drafts the six pages with an evidence list, backs up what it will replace, writes the pages and the two asset files, runs the QA checklist and reports. There is no server to start: open docs/index.html in a browser, or serve docs/ with any static server (for example python3 -m http.server 4590 --bind 127.0.0.1 --directory docs).

Source: SKILL.md "Run" steps 1-8, references/qa.md

Test

The skill ships no automated test. Each run ends with the checklist in references/qa.md: serve docs/ alone, open every page with zero console errors and no request for .md, .json, README or another origin, check light and dark, 375 px with no horizontal scroll, identical navigation on all six pages, one h1, animations that run on their own and stop under reduced motion, then the static checks (links resolve, markers paired, no loader leftovers, no key-shaped strings). The report lists what ran and what is unverified.

Source: references/qa.md

Verify

  1. docs/ holds index.html, setup.html, how-it-works.html, security.html, api.html, demo.html and assets/workdocs.css, assets/workdocs.js.
  2. Open docs/index.html straight from the file system: the navigation lists the six pages and every section ends with a "Source:" line.
  3. The agent's report names created, replaced and untouched pages, the backup folder if any, the evidence gaps, the checks it ran, and the workmap status.

Source: SKILL.md "Run" step 8 and "Done means"

Troubleshooting

SymptomCauseFix
The agent writes a generic README instead of six pagesThe skill was not loadedSay workdocs or /workdocs explicitly; check the folder sits in the agent's skills directory
A page shows a loading placeholder or an empty sectionA legacy page that fetched markdown at open timeRun workdocs again: the migration in references/static.md backs the page up and embeds the content
The flow does not move, the step player shows every step litThe reader's system has reduced motion on, or the tab is hiddenExpected: both stop under prefers-reduced-motion and while the tab is hidden
The agent reports an assets mismatchdocs/assets/workdocs.css or .js differs from the skill's copyYour files are kept; replace them with the skill's copies if you want the current look
The Work map card shows the wrong stateworkmap's SKILL.md is not readable, or docs/workmap.html is missingSee SKILL.md, "Work map": a link card only when both exist; otherwise the pointer card
